# كاشير شاورما العقيله

تطبيق كاشير يعمل على الآيباد من المتصفح ويُثبَّت على الشاشة الرئيسية، ويعمل بدون إنترنت.

- الرابط: https://aqeela-sa.github.io/aqeela-pos/
- البيانات: Firebase (المشروع aqeela-pos).
- الطباعة: طابعة إبسون عبر الشبكة (ePOS-Print)، أو طباعة الآيباد، أو عرض الإيصال على الشاشة.

## الملفات
- `index.html`: الواجهة والتنسيق.
- `app.js`: البرنامج كاملاً.
- `sw.js`: حفظ الملفات للعمل بدون إنترنت.
- `vendor/firebase.js`: مكتبة Firebase الإصدار 12 محفوظة محلياً.
